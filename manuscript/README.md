# Manuscript

`a286874_bounds.tex` is the source and `a286874_bounds.pdf` is the compiled
paper by Siddhartha Mahajan and Paras Chopra.  The bibliography is in
`references.bib`.

From the repository root, rebuild the PDF with:

```sh
make paper
```

The manuscript states the mathematical reductions proved by the ancillary
files.  The executable verification entry point is instead:

```sh
make verify
```
